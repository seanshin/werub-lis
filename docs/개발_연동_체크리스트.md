## A. 외부 연계 (HIS · PACS · 장비)

| 연계 | 상태 | 비고 |
|------|------|------|
| HIS FHIR 자격증명 | ✅ | `hisFhir=true` |
| HIS 오더 폴링(LAB ServiceRequest) | 🔶 | 코드 완비, **`HIS_ORDER_POLL` OFF** → 켜야 실 오더 유입 |
| HIS 결과 발신(FHIR DiagnosticReport / ORU) | ✅ | 라운드트립 검증 |
| **HIS 병리 오더 유입** | ❌ | 폴링이 `category=laboratory`만 수용 → 병리 제외. **발행방식 확인 요청서 발신됨**, 계약 수령 시 PathologyCase 자동생성 구현 |
| HIS Reflex 양방향 오더 | 🔶 | 개발 write 스코프(`lis-dev-reflex`) 발급됨 → **운영자 `.env` 주입 대기** → `flush`→폴링 |
| HIS 환자명 조회(Patient.read) | ✅ | UUID→실이름 폴백 |
| PACS MWL 송신(ORM^O01) | ✅ | **라이브 ACK AA**(병리 화면 버튼 신설) |
| PACS 뷰어(QIDO-RS 딥링크) | ✅ | configured |
| PACS 컷오버 | ✋ | 기술 완결, **병원 실 PID 3건·컷오버 창 대기** |
| 장비 자동수집(ASTM/CSV) | ⏸ | 업체별 인게이지 시 진행([[lis-dual-result-entry]]) |

## B. 내부 UI ↔ 백엔드 배선 (감사 결과 — 백엔드 있으나 화면 없음)

**HIGH (임상 흐름 단절)**
- ❌ **환자 화면 전무** — `GET/POST /patients`·`/patients/:id` 있으나 검색·상세·등록 화면 없음. 모든 흐름에 환자 컨텍스트 부재
- ❌ **오더 상세 드릴다운** — `GET /orders/:orderId`(항목·검체) 미연동
- ❌ **수혈 시행 기록** — `POST /transfusion/administer` 미연동 → 출고→**시행**→부작용 안전루프 단절
- ❌ **유전체 동의→발송→철회 워크플로** — `POST /genomic/consent`·`/sendout`·`/consent/withdraw` 전부 UI 없음(백엔드·검증만 존재). 동의 게이트라 발송이 화면에서 불가

**MED**
- ✅ ACMG 분류 제안(`/genomic/acmg-suggest`) — 유전체 변이 행에 근거 카운트→제안 패널(9c31ff5)
- ✅ 오더 완결도(`/orders/:id/completeness`) — 환자 상세 오더별 완결/부분/미보고 배지+항목 확장(9c31ff5)
- ✅ 비밀번호 변경(`/auth/change-password`) — `/settings/password` 셀프서비스+정책 실시간 검증(9c31ff5)
- ✅ 배양 상세(`/microbiology/cultures/:id`) — 동정 균주별 감수성(AST) 표 뷰(9c31ff5)
- ❌ **연계 운영 콘솔** — 수동 ORU/FHIR 재전송(`/oru`·`/fhir/:sp/send-*`), 수동 오더폴링(`/his/poll-orders`), Reflex 재시도(`/reflex/retry`) 등 화면 없음(reflex outbound 위젯만)

**LOW(대체로 headless/ops)**: `/auth/me`, `/reflex/poll-preorders`, `/reflex/requeue-dlq`, `/pacs/cutover-preflight`

## C. 바코드 정규화 확산

| 화면 | 적용 |
|------|------|
| 결과입력(results/entry) | ✅ 정규화·자동제출·비프 |
| 오더 접수·검체처리 / 검증 조회 / 보고서 스캔칸 | ❌ **미확산** — `lib/barcode.ts` 헬퍼로 동일 적용 필요 |

## D. 설정 토글 (운영자 — 개발 흐름 테스트용)

| 토글 | 현재 | 켜면 |
|------|------|------|
| `HIS_ORDER_POLL=on` | OFF | HIS LAB 오더 자동 유입(5분) |
| `HIS_REFLEX_POLL=on` | OFF | Reflex 승인상태 폴링(10분) |
| `HIS_REFLEX_RETRY=on` | OFF | 발신 실패분 자동 재시도(5분) |
| 개발 write 스코프 `.env` 주입 | 미주입 | Reflex 실발신(flush→PROCESSED) |

## E. 종단 흐름 (E2E) 완결도

| 흐름 | 상태 |
|------|------|
| 진단검사: 오더→접수→결과→자동평가→검증→보고→HIS | ✅ |
| 병리: 오더→케이스→MWL→PACS→뷰어 | ⚠️ **오더 유입만 막힘**(A 병리계약 + B 환자/오더 화면). MWL·뷰어는 ✅ |
| 미생물: 접종→그람예비→동정/감수성→개정 | ✅ (배양상세 UI만 보완 여지) |
| 수혈: 혈액형→교차→출고→**시행**→부작용 | ⚠️ **시행 기록 UI 없음**(B) |
| 유전체: 동의→발송→VCF→큐레이션→확정 | ⚠️ **앞단(동의·발송) UI 없음**(B) |
| Reflex: 결과확정→발신→승인폴링 | 🔶 dev scope 주입 시 실증 |

## 권장 우선순위 (개발 연동 마감)

1. **환자 화면 신설**(검색·상세·등록) — 모든 흐름의 기반, 지금 전무
2. **유전체 동의→발송 UI** + **수혈 시행 기록** — 임상 안전루프 완성
3. **바코드 정규화 확산**(오더·검증·보고서)
4. **연계 운영 콘솔**(수동 재전송·폴링·재시도) — 개발 중 디버깅에 유용
5. **설정 토글 ON**(오더폴링 등) — 실 흐름 유입 테스트
6. 나머지 MED(ACMG·완결도·비번변경·배양상세)

> 외부 게이트(병리 오더 계약·컷오버 실값·dev scope 주입·조직 합의)는 사람 신호 대기. 위 1~4·6은 LIS-side로 지금 진행 가능.
